# GLOBAL_MAP_MECHANICS.md
# Глобальна мапа та час

## 1. Зміна дня і ночі

### Концепція (дизайн)

- День: нормальна видимість.
- Сутінки: обмежена видимість.
- Ніч: видимість на полі бою падає до 2–3 клітинок, -30% влучності стрільби. Зростає шанс нічних засідок.

### Реалізація (v1.7)

Один ігровий день = `PIXELS_PER_DAY = 1500` пікселів руху. Змінна `_day_time` (0..1500) є **єдиним джерелом прогресу**: зростає лише коли загін рухається, одночасно рухає і лічильник днів, і фазу доби.

**Фази (пропорції українського літнього дня):**

| Фаза | Діапазон `phase` (0..1) | Тривалість |
|------|------------------------|------------|
| ☀️ День | 0.00 – 0.57 | 57% |
| 🌅 Захід | 0.57 – 0.64 | 7% |
| 🌙 Ніч | 0.64 – 0.93 | 29% |
| 🌅 Схід | 0.93 – 1.00 | 7% |

**Освітлення (`CanvasModulate`):**
- `C_DAY = Color(1.00, 1.00, 1.00)` — нормальне
- `C_DUSK = Color(0.72, 0.52, 0.32)` — теплий бурштиновий захід
- `C_NIGHT = Color(0.32, 0.34, 0.50)` — холодний синьо-сірий
- `C_DAWN = C_NIGHT.lerp(C_DAY, t)` — плавний перехід

**Радіус огляду туману (змінюється з фазою):**
- День: `FOG_REVEAL_DAY = 280` px
- Ніч: `FOG_REVEAL_NIGHT = 160` px
- Перехідні фази: lerp між значеннями

**Факел загону (`PointLight2D`):**  
Вночі загін несе факел — `PointLight2D` з теплим бурштиновим кольором. Розмір фіксований (не залежить від фази), змінюється лише яскравість: вдень `energy = 0`, в ніч `energy = 1.2`, у перехідних фазах плавний lerp.

## 2. Швидкість руху загону

Залежить від:
- Типу ландшафту (рівнина/дорога — 100%, ліс — 70%, болото — 50%).
- Кількості та типу возів (перевантаження сильно сповільнює).
- Стану загону (поранені, погода, ніч).

## 3. Табір (Camp)

- Зупинка руху, прискорений час.
- Відпочинок, відновлення моралі.
- Споживання харчів і виплата зарплати.
- Можливість призначати табірні ролі.

## 4. Поселення та їхні будівлі

- **Ринок** — купівля/продаж ресурсів і луту.
- **Зброярня / Бронник** — якісна зброя та броня (переважно у великих містах).
- **Таверна** — випивка для підняття моралі, чутки, найм бійців + Tryout (огляд за 20% вартості).
- **Храм / Знахар** — швидке лікування тимчасових травм (каліцтва не лікуються).
- **Тренувальний табір** — тимчасовий бонус до XP.

### 4.1 Поточна реалізація MVP (v1.8)

Поселення (`town`, `village`) відкриваються **мирно** якщо репутація фракції ≥ −19. При кліку одразу відкривається діалог поселення (`_show_location_dialog()`) з трьома секціями:

| Секція | Зміст |
|--------|-------|
| **Торгівля** | Купити провізію (5 шт. за 25 тал.), лікування всього загону (30 тал./поранений) |
| **Крамниця** | Зброя та броня з `world_state["shop_inventory"]` — безлімітний сток для MVP |
| **Найм** | 3 кандидати з випадковими іменами, ціна 50–80 тал. |

**Визначення ворожості (`_is_location_hostile()`):**
- `bandit_camp`, `tatar_camp`, `crown_outpost`, `ruins`, `poi` — завжди ворожі
- `town`, `village` — ворожі лише якщо `faction_rep[faction] ≤ −20`

У мирному діалозі є кнопка **"Атакувати"** для агресивного нападу на гарнізон. Після очищення кнопка зникає, залишається тільки "Покинути".

## 5. Персистенція світу

- Після бою залишки можна мародерувати протягом 1 дня.
- Переможець отримує +20% швидкості на 2 години для переслідування.
- Бійці мають cooldown 10 ігрових хвилин після бою з тим самим загоном.

## 6. Поточна реалізація (v1.8 — 02.06.2026)

**Реалізовано:**
- `WorldMap.tscn` + `WorldMap.gd` — real-time 2D карта 3000×2000px
- Рух гравця кліком (lerp 150 px/s); 2× швидкість множить і рух, і витрати провізії
- **Пауза** (`Space`) — зупиняє гравця, ворогів і час; надпис "ПАУЗА" на екрані
- **Панель швидкості** `[⏸] [1×] [2×]` у TopBar; клавіші `Space` / `1` / `2`
- **День і провізії** — кожні `PIXELS_PER_DAY = 1500` px руху: +1 день, –1 провізія; синхронізовано з циклом доби
- 3 біоми (Ліси / Дике Поле / Кордон) як кольорові зони
- Ріки (Line2D), Озера (Polygon2D) — озера генеруються ≥ 150px від ріки
- Дороги між локаціями (Line2D spanning tree + зигзаг)
- 5–6 ворожих загонів: PATROL → PURSUE → RETURN_TO_BASE
- Бандити патрулюють відрізки доріг; Орда та Crown — зони
- **EncounterDialog**: Атакувати / Уникнути / Говорити (залежить від faction_rep)
  - Після "Уникнути" — 5с cooldown для цього загону (повторна зустріч не спрацьовує)
  - Після "Говорити" — 10с cooldown + +5 репутації з фракцією
  - EnemyParty відновлює патруль одразу після закриття діалогу
- **Cleared-локації**: клік відкриває інформаційне вікно з тематичним текстом замість бойового діалогу
- **Авто-діалог прибуття**: якщо гравець клікнув на далеку локацію і дочекався прибуття — EncounterDialog відкривається автоматично після зупинки загону (без повторного кліку).
- HUD: день, тал., провізії, репутації 3 фракцій, список загону з HP, кнопка `🎒` інвентарю
- **Мирний доступ до поселень** *(v1.8)*: towns/villages з rep ≥ −19 відкриваються без бою — торгівля, крамниця, найм
- **Крамниця** *(v1.8)*: секція в діалозі поселення, зброя/броня/шоломи з `shop_inventory`
- **Панель інвентарю** *(v1.8)*: клавіша `I` — сітка слотів 3×3 + список загону (стиль CharacterSheet)
- **Радіуси взаємодії**: локації `INTERACTION_RADIUS = 18px` (тригер при 27px), вороги бачать/починають бій при `DETECTION_RADIUS = 24px` / `ENCOUNTER_RADIUS = 18px`

**Мораль та голод (v1.8 — реалізовано):**
- Кожен козак має поле `morale` (0–100, початково 100), яке зберігається у `world_state["squad"]` між боями
- При `provisions == 0`: щодня `morale -= 20` для кожного козака (`WorldMap._apply_hunger_effects()`)
- При `morale == 0`: 50% шанс дезертирства — козак видаляється з `ws["squad"]`, повідомлення через `_show_hud_notification()`
- На початку бою при `provisions == 0`: стан `WAVERING`, `stamina *= 0.7` (`BattleManager.gd`)

**Game Over при порожньому загоні (v3.7 — реалізовано):**
- Після видалення дезертирів перевіряється: `squad.is_empty()` → `_show_game_over()`
- Гра зупиняється (`world_ticking = false`, `_player_party.stop()`)
- Показується модальний overlay з панеллю (темний фон, золота рамка):
  - Заголовок: `tr("GAME_OVER_TITLE")` — "Кінець"
  - Текст: `tr("GAME_OVER_DESERT")` — "Усі козаки дезертирували. Ваш загін розпався."
  - Кнопка: `tr("UI_MAIN_MENU")` → перехід на `MainMenu.tscn`

## 7. Туман війни (Fog of War)

### Сітка туману

Карта 3000×2000 px поділена на сітку `FOG_GRID_W=100 × FOG_GRID_H=67` комірок по `FOG_CELL_SIZE=30` px. Кожна комірка зберігає значення `explored` (0–255) у `PackedByteArray` і передається шейдеру через `ImageTexture` (формат RGBA8, R-канал).

### Шари рендерингу

| Вузол | z_index | Призначення |
|-------|---------|-------------|
| `FogLayer` (ColorRect) | 8 | Основний шейдер туману: прозорий в активній зоні, сіра пам'ять в досліджених місцях, світло-блакитний туман у Shroud |
| `CloudLayer` (ColorRect) | 9 | Worley-хмари поверх туману: зникають при наближенні |

### Fog shader (`FogLayer`)

- `color_shroud = vec4(0.80, 0.82, 0.88, 1.0)` — світло-блакитно-сірий туман (terra incognita)
- Плавне коло видимості обчислюється **в шейдері** через `smoothstep(reveal_radius ± soft_edge, dist)` — без пікселів сітки
- Пам'ять (`explored > 0`, поза активною зоною): grayscale через `hint_screen_texture`, яскравість ×0.65
- Перехід shroud → пам'ять: `smoothstep(0.25, 0.0, explored)`

### Cloud shader (`CloudLayer`)

- Три розміри Worley-хмар (scale 3.2 / 6.5 / 11.0) з domain warping через value noise
- Колір хмар `(0.97, 0.97, 0.95)` — майже білий, теплий — поверх холодно-сірого туману
- Хмари видимі лише в `unexplored` зонах (`smoothstep(0.15, 0.0, explored)`)
- Зникають при наближенні: `smoothstep(reveal_radius, reveal_radius * 0.2, dist)`
- Повільний дрейф: `TIME * 0.006` — майже непомітний

### Біомний модифікатор радіусу

| Біом | Модифікатор |
|------|-------------|
| Ліс (`forest`) | ×0.7 |
| Степ (`steppe`) | ×1.15 |
| Кордон | ×1.0 |
