# Козацька Варта — Game Design Document

**Назва гри:** Козацька Варта  
**Жанр:** Тактична покрокова RPG з елементами виживання та логістики (натхнення — Battle Brothers)  
**Сетинг:** Дике Поле, Річ Посполита, Кримське Ханство та Османська загроза — середина XVII століття  
**Статус GDD:** Версія 1.0 (структурована) — 02 квітня 2026

## Як користуватися цією документацією

Ця папка `/GDD/` містить повну технічну та дизайнерську документацію гри.

### Структура папок

- **00_*** — Службові файли (цей README, індекс, історія змін)
- **01_CORE/** — Основна концепція, дизайн-документ, стартові сценарії
- **02_WORLD_AND_FACTIONS/** — Світ, фракції, складність, квести
- **03_COMBAT/** — Бойова система, формули, terrain, вороги
- **04_UNITS_AND_PROGRESSION/** — Перки, трейти, прогресія, класи юнітів
- **05_ECONOMY_AND_LOGISTICS/** — Економіка, крафт, лут, табір, вози
- **06_UI_AND_AUDIO/** — Інтерфейс та звук
- **07_TECHNICAL/** — Технічна архітектура, збереження, локалізація
- **08_CONTENT/** — Випадкові події, амбіції, репутація

### Правила роботи з документами
- Кожен файл містить лише одну тему.
- Якщо файл стає надто великим (> 8000 байт) — його можна розбити.
- Усі таблиці використовують однаковий стиль markdown.
- Версію документа оновлюй у заголовку кожного файлу.
- Перед зміною важливої механіки — спочатку внеси зміни в цей GDD.

### Наступні кроки після цієї структури
1. Перевірка та затвердження всіх файлів
2. Створення детального плану реалізації в Godot
3. MVP-прототип (бойова система + 1 сцена)
