# Унікальний лут (Famed / Named Items)

- Генеруються тільки з Чемпіонів або в легендарних локаціях.
- Мають 1–2 випадкових модифікатори (+10–30% шкоди, +10–20% Armor Pen тощо).
- Колір назви: червоний або золотий.

**Таємні локації:** Закинута кузня характерника, Проклятий монастир, Курган Сіркового побратима.
