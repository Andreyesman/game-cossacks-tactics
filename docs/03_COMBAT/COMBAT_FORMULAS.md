# Формули бою

## 1. Шанс влучання
**Шанс (%) = Навичка атакуючого – Захист цілі + Модифікатори**

- Мінімум **5%**, максимум **95%** (константи `CHANCE_MIN/CHANCE_MAX` у `Globals.gd`).
- Модифікатор «Оточення»: **+5%** за кожного додаткового ворога біля цілі після першого (`flanking_bonus = (adjacent_enemies - 1) * 5`).
- Модифікатор «Висота»: **+10%** якщо атакуючий вище, **-10%** якщо нижче (тільки ближній бій).
- Модифікатор «Мораль»: +10 (Впевнений), 0 (Спокійний), -10 (Вагається), -20 (Зламаний), -30 (Тікає).

### Формула дальнього бою (мушкет)
**Шанс = base_ranged_skill + morale_modifier + distance_bonus – target_defense – terrain_penalty**
- `distance_bonus = max(0, weapon_range – dist) * 5` (більший бонус за ближчу відстань, але при dist=1 — нуль).
- Штраф стрільби в ZoC: **-40%**.
- Штраф кожного куща між стрільцем і ціллю: **-20%**.

## 2. Влучання в голову
Базовий шанс — **15%**.  
Модифікатори:
- Обушок (Lash) — 100% в голову.
- Спеціальні риси / перки — до +15%.

При влучанні в голову шкода ×1.5 (і по HP, і по броні шолома).

## 3. Зона Контролю та опортуністичні атаки
Будь-яка спроба вийти з ZoC або почати перезарядку/постріл в ZoC → безкоштовна атака ворога.

## 4. Перевірка Моралі (Resolve Check)
**Шанс витримати = base_resolve – штрафи (кидок нижче = успіх)**

- Успіх при **ТИСКУ** (penalty > 0): нічого не змінюється.
- Провал при **ТИСКУ**: мораль падає на 1 сходинку.
- Успіх при **ВІДНОВЛЕННІ** (penalty ≤ 0): мораль покращується на 1 сходинку.
- Успіх при **Rally** (penalty = -20): примусово покращує мораль союзників у радіусі 4.

Приклади штрафів:
- Оточення 2+ ворогами: `(flankers - 1) * 5` за кожного після першого
- Тяжке поранення (>25% HP за хід): штраф **10**
- Rally (Zgurtuvanniya): бонус **-20** (позитивний)
- Смерть союзника → **ланцюгова паніка** у радіусі 3 з штрафом **10**
