# Бестіарій: Розбійники та відступники

## 1. Основні типи

- **Лісові розбійники** — сокири, ножі, засідки.
- **Степові харцизи** — кінні, аркани, списи.
- **Дезертири** — добра зброя, низька мораль.

## 2. Чемпіони (міні-боси)
Кожен елітний ворог має ~1–2% шанс стати Чемпіоном (+50% до всіх статів).  
Гарантовано дропає **Famed/Named** предмет при вбивстві.
