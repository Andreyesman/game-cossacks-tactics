# Бестіарій: Регулярні армії

## 1. Річ Посполита
- Крилатий Гусар — таранний удар.
- Панцирний козак — гнучкий натиск.
- Гайдук — бердиш, розбиття зброї.

## 2. Кримське Ханство
- Кінний лучник — стріляє після руху.
- Улан — удар і миттєвий відхід.
- Арканник — притягує юнітів.

## 3. Османська імперія
- Яничар — залповий вогонь.
- Сипах — важка кавалерія.
- Топчу — фальконет (AOE).
