# Стартові сценарії компанії

Походження загону визначає стартові умови, ресурси, репутацію та стиль проходження.

## 1. Стандартний сценарій

**«Новий Отаман»**  
Опис: Ви щойно зібрали кількох товаришів для заробітку найманством.  
Старт: 3 базових бійця, мінімальна екіпіровка, нейтральна репутація, трохи золота і харчів.  
Стиль: Класичний баланс. Найкращий вибір для першого проходження.

## 2. Спеціалізовані сценарії

**«Торговий Караван»**  
Опис: Представники гільдії купців з охороною.  
Старт: 0 бійців, 2 великих вози, великий запас золота, добра торгівельна репутація.  
Бонуси: +10% до ціни продажу, знижки у чумаків.  
Штрафи: Повільніший рух, немає важких бойових контрактів.

**«Дезертири з Корони»**  
Опис: Втікли з польської армії після жорстокого наказу.  
Старт: 3 елітних солдати з доброю бронею та мушкетами.  
Бонуси: Висока ініціатива, сильна стартова екіпіровка.  
Штрафи: Низька мораль, ворожість від Корони, полювання патрулів.

**«Самотній Вовк / Характерник»** (Хардкор)  
Опис: Легендарний відлюдник-характерник.  
Старт: Лише ваш аватар (4 рівень, елітна екіпіровка).  
Бонуси: Авторитет, немає зарплати, чемпіонські стати.  
Штрафи: Максимум 12 людей у загоні. Смерть аватара = Game Over.
