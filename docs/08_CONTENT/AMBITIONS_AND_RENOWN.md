# Слава, репутація та амбіції

## 1. Слава (Renown)
Зростає за:
- Успішні 3-зіркові контракти
- Вбивство Чемпіонів
- Виконання Амбіцій
- Вирішення глобальних криз

Висока Слава відкриває елітних найманців (Характерники, Сердюки-ветерани) та найкращі контракти.

## 2. Система Амбіцій
Раз на кілька тижнів гравець обирає одну активну Амбіцію.

**Приклади:**
- Накопичити 5000 талерів
- Відкрити 20 локацій у тумані війни
- Перемогти банду з 15+ ординців
- Заснувати власну Січ (головна кінцева амбіція)

Нагорода: великий приріст Слави + тимчасовий бонус настрою всього загону до «Ейфоричного».

## 3. Головна мета — Заснування Січі
Багатоетапний ендгейм:
1. Отримати Золоту Грамоту після кризи.
2. Обрати місце (острів, курган, фортеця).
3. Доставити 50 000 талерів + 500 інструментів + 1000 провіанту.
4. Відбити 3 масштабні облоги.

Після успіху — епілог для кожного ветерана + перехід у вільний пісочничний режим.
