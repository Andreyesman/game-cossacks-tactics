# Випадкові подорожні події

Порожні переїзди між містами — це не просто таймер. Під час руху по глобальній мапі з певною ймовірністю спрацьовують текстові події (pop-up).

## Механіка
- Рух зупиняється.
- З’являється атмосферне вікно з описом ситуації.
- Гравець обирає 1–3 варіанти дій.
- Наслідки: зміна настрою, травми, лут, репутація, золото/їжа.

## Приклади стандартних подій
- **Бійка за їжу** — два козаки побилися через останній шматок м’яса.
- **Покинутий чумацький віз** — можна витратити час на мародерство (ризик засідки).
- **Сільська суперечка** — селяни просять розсудити крадія.

## Спеціальні варіанти залежно від походження
- Наявність **Колишнього Монаха** → мирне вирішення конфлікту + бонус до репутації.
- Наявність **Злодія / Каторжника** → ювелірне відкриття скрині без пасток.
- Наявність **Мисливця / Пластуна** → автоматичне виявлення засідки попереду.
