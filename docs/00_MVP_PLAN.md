## 0. Контекст та мотивація

### 0.1 Що вже є (станом на v1.7)

✅ **Бойова система** — повністю функціональна: рух, атаки, ШІ з пріоритетами, мораль (5 станів), ZoC, LoS, рикошети, дружній вогонь, відступ, Riposte, Rally, TurnQueueUI, CharacterSheet

✅ **Глобальна карта** — real-time 2D, рух кліком, швидкість 1×/2×, пауза, цикл доби (CanvasModulate + PointLight2D), fog of war (шейдери + worley noise)

✅ **Процедурна генерація** — WorldGenerator (3 біоми, ріки, озера, дороги, 6 локацій, 5 ворожих загонів), WFC для бойових карт 16×16

✅ **Кампанія** — CampaignManager, SaveManager v2 (JSON), MainMenu, BattleResultScreen, EncounterDialog (3 кнопки: Атакувати / Уникнути / Говорити)

✅ **Юніти** — 4 козаки (Ничипір, Гаврило, Тимофій, Панько) + 7 типів ворогів, WeaponResource, AttackAction, CombatUnit ~1100 рядків

✅ **Економіка в даних** — талери, провізії, репутація 3 фракцій зберігаються у `world_state`

### 0.2 Головна проблема

**Зараз гра закінчується після першого бою.** Ви перемогли — отримали талери — і що далі?
- Немає найму нових бійців
- Немає торгівлі (на що витрачати талери?)
- Немає ремонту/лікування
- Немає заміни спорядження

**Без progression loop немає причини грати далі після 2-3 битв.**

### 0.3 Що таке MVP

> **"Козацька Варта" v1.0 — це:**
> Покрокова тактична RPG, де ви керуєте загоном із 4-8 козаків XVII ст. Переміщуєтесь по мапі Дикого Поля, зустрічаєте ворожі загони, ведете тактичні бої. Між боями — наймаєте нових бійців, купуєте/ремонтуєте спорядження в поселеннях. Смерть постійна, мораль впливає на бій. Мета — вижити якомога довше та наростити славу.

**Обсяг:** 180-245 годин роботи = **8-12 місяців при 6 год/тиждень**.

## 2. Детальний план по фазах

### ФАЗА 1: Progression Loop
**Тривалість:** 8-10 тижнів (95-120 годин)  
**Мета:** Гра playable на 5+ битв поспіль  
**Критерій успіху:** Зіграти в кампанію з 5+ боями, де:
- 1+ козак гине
- 1+ нового наймаєш
- 1+ купуєш обладунки
- 1+ продаєш лут
- HP відновлюється в поселеннях

#### 1.1 Лікування в поселеннях
- [ ] Визначити типи локацій, де можна лікувати (`town`, `village`)
- [ ] При кліку на таку локацію — опція "Лікувати" в EncounterDialog
- [ ] Вартість: 5 талерів за юніта АБО 1 провізія (зручніше — талери, провізії лишимо для табору)
- [ ] Ефект: HP → max_hp
- [ ] Зберегти в `world_state["squad"]`

**GDScript-сніпет для панелі лікування:**
```gdscript
# src/ui/HealingPanel.gd
extends PanelContainer

var _world_state: Dictionary
var _squad: Array

func _ready() -> void:
    _world_state = CampaignManager.world_state
    _squad = _world_state.get("squad", [])

func _heal_unit(unit_name: String) -> void:
    for unit in _squad:
        if unit["name"] == unit_name and unit["hp"] < unit["max_hp"]:
            if _world_state["thalers"] < 5:
                _show_message("Недостатньо талерів!")
                return
            _world_state["thalers"] -= 5
            unit["hp"] = unit["max_hp"]
            CampaignManager.save_world_state()
            _refresh()
            break

func _refresh() -> void:
    # Перебудувати список юнітів
    pass
```

```gdscript
# src/core/Localization.gd
extends Node

const _translations: Dictionary = {
    "uk": "res://locale/uk.json",
    "en": "res://locale/en.json"
}

func set_language(lang: String) -> void:
    if not _translations.has(lang):
        push_warning("Unknown language: %s" % lang)
        return
    var file := FileAccess.open(_translations[lang], FileAccess.READ)
    if file:
        var data = JSON.parse_string(file.get_as_text())
        TranslationServer.add_translation(data)
        TranslationServer.set_locale(lang)

func tr(key: String) -> String:
    return TranslationServer.translate(key)
```

## 7. Після релізу (Фаза 5+)

### 7.1 Пріоритети зворотного зв'язку
1. Що найчастіше скаржаться? → виправляти першим
2. Що найбільше хвалять? → підсилювати
3. Які фічі просять найчастіше? → додавати в наступний патч

### 7.2 Roadmap після v1.0
- v1.1 (1-2 місяці): баг-фікси, баланс, дрібні полірування
- v1.2 (3-4 місяці): 2 фракції (Корона + Січ), більше найманців
- v1.5 (6+ місяців): 3 фракції, випадкові події, ремесло
- v2.0 (рік+): ендгейм з глобальними кризами і Січчю

### 7.3 Паралельні проєкти (для профілактики вигорання)
- Між Фазами 1-2 — 2 тижні на маленький **"mini-game" проєкт** (1-2 тижні)
- Це не відволікання, це **профілактика** burnout
- Приклади: простий 2D-платформер, візуальна новела, 1 вечір jam-game

## 9. Фінальні думки

У вас **немає проблем з ідеєю чи технічною реалізацією** — у вас проблема з **дисципліною фінішу**. Документація описує гру, яка в 5-10 разів більша за те, що потрібно для першого релізу. Це класичний trap, в який потрапляють всі інді-розробники.

**Головна формула:**
```
Успіх = Скорчений scope × Завершені фази × Ранній реліз
```

Кожна завершена фаза = мотивація на наступну.  
Кожен реліз = зворотний зв'язок від реальних гравців.  
Кожен "ще 2 роки до релізу" = крок до вигорання.

**Бажаю успіхів. Проєкт реально вартий того, щоб його завершити.**
