# Система перків та розвиток

Кожен юніт отримує **10 очок перків** до 11-го рівня.  
З 12-го рівня перки більше не даються — лише невелике підвищення характеристик.

## Структура прогресії
- Рівень 1: старт (без перків)
- Рівні 2–11: +1 очко перку за рівень
- Рівні 12+: тільки +1 до трьох характеристик на рівень

Перки розділені на тіри. Для перку з Тір-3+ потрібно витратити мінімум 2 очки в попередніх тірах.
