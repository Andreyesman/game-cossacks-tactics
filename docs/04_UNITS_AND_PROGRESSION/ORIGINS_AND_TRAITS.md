# Унікальні особливості походжень

## Рекрут
- Втікач із кріпацтва → +10 Витривалість
- Син реєстрового → +5 Влучність + шабля
- Бурсак-утікач → +10 Мораль +5 Ініціатива

## Мушкетер
- Мисливець → +10% Влучність +1 огляд
- Колишній гайдук → +5 Захист
- Міський пушкар → -5% осічки
