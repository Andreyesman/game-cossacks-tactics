# UI_UX_LAYOUTS.md
# Інтерфейс та Взаємодія (UI/UX Layouts)

## 1. Тактичний Бойовий HUD (Tactical Screen)

- **Панель бійця** (нижній лівий кут): Портрет, шкали HP (червона), Stamina (жовта), Мораль (блакитна), стан броні.
- **Центральна панель навичок** (bottom center): 4–8 активних слотів зі гарячими клавішами, вартістю AP та Stamina.
  - **ПКМ (права кнопка)** — скасовує вибрану навичку і повертає до режиму переміщення. Незалежна гілка `if` в `_unhandled_input`, не залежить від лівого кліку.
- **Журнал бою** (правий кут): Текстові події. Жовті рядки `[Підказка]` — одноразові геймплейні підказки (не повторюються в межах одного бою).
- **Floating HUD**: При наведенні на ворога — шанс влучити (%), HP, стан Моралі.
- **Зона руху**: жовта заливка досяжних клітинок + золотий контур (1.5px) по межі зони. Попередній шлях видно постійно, але обрізається на межі досяжності.

### Tutorial HUD (тільки під час tutorial-бою)

Активується якщо `CampaignManager.active_battle_config["is_tutorial"] == true`. У звичайних боях не показується.

- **Tutorial-панель** (`Control`, 45% ширини viewport): розміщується по центру горизонтально, над UnitPanel (`y = vp.y - unit_panel.size.y - panel_h - 30`). Висота фіксована 50 px.
  - Фон: `ColorRect` `Color(0.07, 0.065, 0.055, 0.95)`
  - `Label` з текстом підказки (шрифт KellySlab 16px, колір `Color(0.85, 0.8, 0.6)`, `clip_text = true`)
  - Кнопка **"Пропустити"** (110×32 px) — викликає `finish_battle(true)` → `tutorial_done = true` → WorldMap
  - Fade-in/out 0.3 сек через `create_tween()`; позиція оновлюється при `size_changed`

**5 кроків підказок (послідовно, без блокування дій):**

| # | Показується при | Зникає при |
|---|----------------|-----------|
| 1 | Перший хід козака (team 0) | Вибір навички |
| 2 | Навичку вибрано | HP ворогів зменшились |
| 3 | Козак атакував (HP знизилось) | End Turn |
| 4 | Хід ворога (team 1) | Наступний хід козака |
| 5 | Другий хід козака | Будь-яка дія або End Turn |

- **`[Підказка]` в CombatLog вимкнені** під час tutorial (`_maybe_combat_hint` → `return false`)

**Реалізація:** `BattleManager._build_tutorial_panel()`, `_reposition_tutorial_panel()`, `_show_tutorial_step()`, `_hide_tutorial_panel()`, `_get_total_enemy_hp()`

## 2. Глобальна Мапа (World Map HUD)

### 2.1 TopBar — три пергаментні панелі *(Figma-дизайн, v4.2 → v4.6)*

`Control (PRESET_TOP_WIDE, custom_minimum_size.y = 68px)` містить три дочірніх `PanelContainer`. Спільний стиль: фон `#F6F0DA`, рамка `#585551` 2px. **Висота всіх трьох панелей: 56px** (Figma-точно). Kelly Slab font каскадується автоматично з глобального `assets/theme/game_theme.tres` (v4.3). Колір тексту Label `#585551` — через `Label/colors/font_color` у Theme. Під панелями (offset_top = 72) — `_pause_label`, `_discovery_panel`, `_inventory_panel`.

#### Ліва панель (День + Ресурси)

`anchor_right = 0.0`, `GROW_DIRECTION_END` — росте вправо від лівого краю. `py=15 px=24` (15px замість Figma 16px — компенсація Godot font metrics: Label font_size=18 дає 26px замість CSS 24px; 15+26+15=56px). `corner_radius_bottom_right = 16`.

`HBoxContainer (separation=12)`:

| Елемент | Структура | Тип |
|---------|-----------|-----|
| Фаза доби | `day_hbox (sep=4)` → `_time_phase_label` ("☀️ День") + `_day_label` ("1-й") | `Label font_size=18` |
| Таляри | `money_hbox (sep=4)` → `coin_icon ("🪙" 24px)` + `_thalers_label` | `Label font_size=18` |
| Провізії | `food_hbox (sep=4)` → `bread_icon ("🍞" 24px)` + `_provisions_label` | `Label font_size=18` |

`_time_phase_label.text` оновлюється в `_update_day_night()` → `tr("TIME_DAY/DUSK/NIGHT/DAWN")`. Переклади містять emoji: `"☀️ День"`, `"🌅 Захід"`, `"🌙 Ніч"`, `"🌅 Схід"`. Колір тексту статичний `#585551`.

#### Центральна панель (Швидкість)

`anchor_left = anchor_right = 0.5`, `GROW_DIRECTION_BOTH` — центрується горизонтально. `py=12 px=24`. `corner_radius_bottom_left = corner_radius_bottom_right = 32`.

`HBoxContainer (separation=12, alignment=CENTER)`. Всі три кнопки — `TextureButton (flat=false, ignore_texture_size=true, STRETCH_KEEP_ASPECT_CENTERED, focus_mode=NONE)`. Висота контенту = 32px → 12+32+12=56px.

| Кнопка | Розмір | SVG файли (assets/sprites/ui/) |
|--------|--------|-------------------------------|
| PauseButton (`_pause_btn`) | 32×32 | `speed_pause_default/hover/active.svg` — дві смуги з noise filter |
| PlayButton 1× (`_speed1_btn`) | 32×32 | `speed_play_default/hover/active.svg` — трикутник (автентичні Figma шляхи) |
| ForwardButton 2× (`_speed2_btn`) | 40×32 | `speed_fwd_default/hover/active.svg` — composite: два трикутники в nested SVG |

**Кольори SVG по станах:** Default=`#BEBBAC`, Hover=`#E4CD80`, Active=`#FCCC28`. Stroke: pause=`#585551`, play+fwd-tri2=`#080707`, fwd-tri1=`#585551`.

**Radio-group поведінка** (`_apply_speed_btn_state()`):
- **Активна кнопка:** `disabled=true`; `texture_normal/hover/pressed/disabled = *_active.svg` — завжди золота, не реагує на hover/click
- **Неактивна кнопка:** `disabled=false`; `texture_normal=*_default`, `texture_hover=*_hover`, `texture_pressed=*_active`

`_refresh_speed_btns()` визначає стани через `_is_paused` і `_speed_multiplier`, викликає `_apply_speed_btn_state()` для кожної кнопки.

Хелпер `_make_speed_tex_btn(tex_n, tex_h, tex_p, tip, size) → TextureButton` — конструює TextureButton з FloatingLabel tooltip.
`_make_speed_icon_btn(tip) → Button` — залишено для `_inventory_btn` (Button з текстом).

#### Права панель (Репутація + Інвентар)

`anchor_left = anchor_right = 1.0`, `GROW_DIRECTION_BEGIN` — росте вліво від правого краю. `py=12 px=24`. `corner_radius_bottom_left = 16`. Висота = 12+32+12=56px (inventory button 32px — задається через Control wrapper).

`HBoxContainer (separation=12)`:

| Елемент | Структура |
|---------|-----------|
| Корона | `f_hbox (sep=4)` → `Label "Корона:"` + `val_lbl (min_width=36px)` |
| Січ | `f_hbox (sep=4)` → `Label "Січ:"` + `val_lbl (min_width=36px)` |
| Орда | `f_hbox (sep=4)` → `Label "Орда"` (без двокрапки) + `val_lbl (min_width=36px)` |
| Інвентар | `Control inv_box (32×32)` → `_inventory_btn Button (PRESET_FULL_RECT, "⛺️", font_size=28)` |

`_inventory_btn` загорнуто в `Control (custom_minimum_size=32×32)` щоб `HBoxContainer` бачив 32px висоту (Button з emoji font_size=28 без обгортки вимагає 41px через Godot font metrics).

`_rep_labels: Dictionary[String, Label]` — зберігає тільки value-labels; оновлюється в `_update_hud()`.

### 2.2 Клавіатурні скорочення

- `Space` — пауза / зняття паузи (зупиняє гравця, ворогів і час; показує надпис "ПАУЗА")
- `1` — 1× швидкість
- `2` — 2× швидкість (рух і витрати провізії вдвічі швидше)
- `I` — відкрити/закрити панель інвентарю

### 2.3 Ліва нижня і модальні панелі

**Ліва нижня панель (SquadPanel):**
- Список козаків з поточним і максимальним HP; колір залежить від відсотка HP.

**Модальне вікно зустрічі (EncounterDialog):**
- Назва ворога або локації, приблизна здобич
- Кнопки: Атакувати / Уникнути / Говорити (набір залежить від репутації з фракцією)

## 3. Екран Інвентарю та Менеджменту (Squad Screen)

- Ліва колонка: Ростер (до 20 козаків).
- Центр: Лялька персонажа з слотами екіпірування.
- Права частина: Спільний інвентар возів.
- Бічна панель: Детальні стати.

### 3.1 Панель інвентарю на глобальній карті *(реалізовано v1.8, оновлено v4.0.5)*

Права бічна панель (340px), відкривається клавішею `I` або кнопкою `🎒` у TopBar. Побудована процедурно в `WorldMap.gd`.

**Структура (зверху вниз):**

1. **ЗАГІН** — `VBoxContainer (separation=4)`. Кожна кнопка — горизонтальна, на всю ширину:
   - `Button (SIZE_EXPAND_FILL, min_height=48)` → `HBoxContainer (sep=10)`:
     - `TextureRect 40×40` (`{name}_front.png`, `EXPAND_IGNORE_SIZE`, `STRETCH_KEEP_ASPECT_CENTERED`, `SIZE_SHRINK_CENTER` по вертикалі)
     - `Label font_size 14` (ім'я, `SIZE_EXPAND_FILL`, `vertical_alignment = CENTER`)
   - Маппінг `NAME_TO_SPRITE`: Ничипір→`nychypir`, Гаврило→`havrylo`, Тимофій→`tymofiy`, Панько→`panko`; рекрути — fallback по індексу
   - Обраний: `border Color(0.89, 0.8, 0.42) 2px`; неактивний: `Color(0.45, 0.35, 0.12) 1px`; фон: `Color(0.1, 0.09, 0.07)`
   - Клік переключає активного козака

2. **СПОРЯДЖЕННЯ** — заголовок козака (`font_size 20`, `Color(1.0, 0.85, 0.3)`) + HP/рівень. Сітка слотів 3×3, стиль ідентичний `CharacterSheet._equipment_slot()`:
   - Ряд 1: [Прикраса] [Шолом] [Набої] — `Vector2(100, 100)` кожен
   - Ряд 2: [Зброя] [Броня] [Щит] — `Vector2(100, 180)` кожен
   - Ряд 3: [Пояс] [Пояс] [Пояс] — `Vector2(100, 100)` кожен
   - Розмір слоту визначається через `_cell_idx / 3`: рядок 1 → `100×180`, решта → `100×100`
   - Заповнений слот: `bg Color(0.13, 0.11, 0.07)`, `border Color(0.48, 0.38, 0.13)`
   - PNG-іконка: `TextureRect SIZE_EXPAND_FILL`, `custom_minimum_size = (p_x−10, minf(p_x−10, p_y−50))`, назва в `MarginContainer 5px`, `line_spacing −2`
   - Fallback: Label з емодзі
   - Клік на зайнятий слот = зняти предмет у `squad_inventory`
   - Під сіткою: стати (ближній бій, захист, броня, шолом)

3. **ІНВЕНТАР ЗАГОНУ** — ScrollContainer зі списком `squad_inventory`. Для кожного предмета: назва (тип), `[⬆ Озброїти]` (на обраного козака), `[Продати N]` (активна лише в поселенні).

## 4. Технічні стандарти

- **4px Grid** для всіх елементів.
- Мінімальний розмір тексту: **16 px**.
- Основний текст: **20 px**.
- Заголовки: **24 px**.
- Колірна палітра: приглушені історичні кольори + яскраві акценти (Gold, Cyan, Crimson).
## 5. Налаштування екрану та камери (Camera & Viewport)

- **Базова роздільна здатність:** 1920x1080 (Full HD).
- **Масштабування (Stretch Mode):** `canvas_items` + `expand`. Забезпечує адаптивність під Ultrawide та інші формати без чорних смуг.
- **Вільна камера (Panning):** 
  - Скролінг клавішами `W, A, S, D` або стрілочками.
  - Перетягування (Drag) карти затиснутою середньою кнопкою миші.
  - Вбудовані ліміти камери, щоб не загубити поле бою (`X: -500..500`, `Y: 200..1000`).
- **Зумування (Zoom):**
  - Базовий (дефолтний) зум: **x1.0**.
  - Доступні фіксовані рівні масштабу: `[0.5, 0.75, 1.0, 1.25]`.
  - Керування: коліщатко миші або клавіші `+` та `-`.
  - Динамічний індикатор (наприклад, `Зум: x0.75`) справа зверху екрану, який автоматично приховується через 1.5с.

## 6. Черга ходів (Turn Queue UI)

Вгорі праворуч екрану — ряд іконок, що показує порядок ходів у поточному раунді.

- **Активний юніт** (той, хто ходить зараз): велика іконка 80×80 пікселів, кольорова рамка (синя для козаків, червона для ворогів)
- **Наступні у черзі**: іконки 60×60 пікселів
- **Вже походили**: маленькі іконки 52×52, приглушені

Під кожною іконкою — тонка смужка HP, що оновлюється в реальному часі. При наведенні на іконку — юніт підсвічується на карті, і навпаки.

Зліва від черги — табличка з номером поточного раунду і назвою локації (наприклад, "РАУНД 3 / Ліс"). Колір назви відповідає типу місцевості: золотий для степу, зелений для лісу, оливковий для болота, блакитний для річки.

**Виправлення (v1.6):** Видалено подвійний `pop_front()` у `BattleManager._ready()`, через який перший юніт у черзі (найвища ініціатива) пропадав із панелі при старті бою. Тепер `initialize_queue()` заповнює повну чергу, а `start_next_unit_turn` (deferred) коректно витягує першого.

## 7. Екран результатів бою (Battle Result Screen)

З'являється після закінчення бою (перемога або поразка). Показує підсумки:

- Статистика кожного юніта: скільки шкоди завдав, скільки отримав, скільки XP заробив, чи підвищився рівень
- Хто загинув у бою
- Перехід назад у меню або до наступного бою

### 7.1 Секція "Здобич" (`_loot_slot()`, `_build_loot_column()`)

Сітка 2 колонки. Кожен слот — `PanelContainer 90×90`.

| Тип слоту | Вміст |
|-----------|-------|
| Є PNG-іконка | `TextureRect 56×56` (`EXPAND_IGNORE_SIZE`, `STRETCH_KEEP_ASPECT_CENTERED`); назви немає — показується через `FloatingLabel` при hover |
| Немає іконки (💰 або fallback) | `Label` з емодзі (font_size 32) + `Label` з текстом (font_size 12, autowrap) |

Hover-tooltip: `p.mouse_filter = MOUSE_FILTER_STOP`, `mouse_entered → FloatingLabel.show_label(item_name)`, `mouse_exited → FloatingLabel.hide_label()`.

## 8. Аркуш персонажа (Character Sheet)

Відкривається кліком на **портрет юніта** в панелі внизу ліворуч. Повноекранне вікно поверх бою з детальним профілем:

- Портрет, ім'я, рівень, прогрес до наступного рівня (XP-бар)
- Всі базові стати: HP, Stamina, ініціатива, навичка ближнього бою, дальнього бою, захист, рішучість
- Спорядження по слотах: зброя, броня, шолом, пояс (витратні предмети)
- Перелік всіх доступних навичок атаки з описами
- Активні поранення і їхні штрафи
- Походження та риси характеру

Закривається кліком за межами вікна або повторним кліком на портрет.

### Слоти спорядження (`_equipment_slot()`)

Кожен слот — `PanelContainer` з `VBoxContainer` всередині. Розмір слоту передається через `p_size: Vector2` (100×100 для малих, 100×180 для зброї/броні).

**Іконка предмета:**
- Якщо є PNG: `TextureRect` квадратний `min(p_size.x−20, p_size.y−50)` з `SIZE_SHRINK_CENTER`. Займає більшу частину слоту.
- Інакше: `Label` з емодзі, `font_size 32` (слоти >120px) або `24`.

**Назва предмета:**
- `Label`, `font_size 12`, `autowrap_mode = AUTOWRAP_WORD_SMART`
- `custom_minimum_size.x = p_size.x − 10` — обмежує ширину, довгі назви переносяться на 2 рядки
- `line_spacing = −2` — компенсує зайвий відступ між рядками

## 9. Завантажувальний екран (Loading Screen)

З'являється між головним меню і боєм. Відображає напис "Завантаження битви..." по центру екрану — з анімованими крапками, що з'являються по черзі. Поки гравець це бачить, Godot у фоновому потоці завантажує всі ресурси сцени бою. Коли завантаження завершено — автоматично переходить до бою.

## 10. Геймплейні підказки в журналі бою *(реалізовано v2.1)*

Жовті рядки `[Підказка]` з'являються в `CombatLog` один раз за бій при першому тригері. Реалізовано через `BattleManager._maybe_combat_hint(key, text)`. Скидаються автоматично при кожному новому бою.

| Тригер | Текст підказки |
|--------|---------------|
| Перший хід козака | "Клікніть на ворога в зоні атаки, щоб вдарити. ПКМ скасовує навичку." |
| Витривалість < 30% | "Витривалість низька — використайте Відпочинок для відновлення." |
| Мораль WAVERING або нижче | "Мораль падає! Згуртування (Rally) може допомогти." |
| Вихід із ZoC (козак) | "Вихід із зони контролю ворога дає йому безкоштовну атаку." |
| Перший постріл мушкета | "Після пострілу мушкет треба перезарядити." |

Не більше однієї підказки за хід — в `start_next_unit_turn()` ланцюг `if not _hint` зупиняється після першого спрацювання.

## 11. Панель налаштувань у MainMenu *(реалізовано v3.3)*

Відкривається кнопкою "Налаштування" (між "Продовжити" та "Вийти"). Lazy-created — будується один раз при першому відкритті.

**Кнопка в MainMenu:**
- Стиль: `_apply_text_style()` — як кнопки "Продовжити" / "Вийти"
- Включена в `_anim_nodes` → бере участь у fade-in анімації входу

**Модальна панель:**
```
[Налаштування]
──────────────────────────────
Мова:     [Українська ▼]
──────────────────────────────
Музика 70%
[━━━━━━━━━━●──────────────────]
Звуки 80%
[━━━━━━━━━━━━━━━●──────────────]

              [Закрити]
```

**Стиль:**
- Ширина панелі: 400px, `custom_minimum_size`
- Фон: `Color(0.07, 0.065, 0.055)`, рамка: `Color(0.65, 0.5, 0.18)`, 2px, corner 4px
- Заголовок: 22px, `Color(1.0, 0.85, 0.3)`
- Лейбли: 16px, `Color(0.85, 0.8, 0.6)`
